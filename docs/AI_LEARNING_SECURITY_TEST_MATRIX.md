# AI Learning Center — Security Test Matrix

**Assessment:** targeted automated security checks pass for the tested current single-role workspace model. The user confirmed workspace-wide administrator access on 2026-11-11. The important residuals are arbitrary names/addresses in bounded admin free text, unreviewed production traces, unexecuted manual accessibility checks, and real-model behavior not tested. The current risk-based release decision defers manual accessibility to follow-up and live-model behavior to controlled Learning rollout; neither is marked PASS. This is not a penetration-test report.

## Evidence and test boundaries

- Isolated route tests: test/learning-security.test.js.
- Browser security probes: e2e/learning.browser.e2e.js against a local server and isolated MySQL.
- Rule safety and prompt hierarchy: test/learning.test.js and generation tests.
- Transaction and lifecycle cases: test/learning.mysql.integration.test.js and related MySQL tests.
- Shadow resource limits: test/learning-shadow.test.js, test/learning-shadow-execution.test.js, test/learning-shadow.mysql.integration.test.js, and test/learning-shadow.database-restart.test.js.
- Current-session verification ran `npm test`, the full serial disposable-MySQL suite, isolated migration-upgrade and real MySQL-restart tests, and local Chrome E2E. Exact commands/results are in [AI_LEARNING_P1_ACCEPTANCE.md](AI_LEARNING_P1_ACCEPTANCE.md).
- Login/logout/session-expiry and stored-XSS coverage were extended in this closure pass. A deterministic conflict-check false negative for direct Tebar API-call instructions was reproduced and fixed.
